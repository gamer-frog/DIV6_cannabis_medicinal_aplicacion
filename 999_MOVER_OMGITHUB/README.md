# 999_MOVER_OMGITHUB — staging (omgithub)

Carpeta de **staging** para ir juntando data/apps candidatas a mover a otro repo trabajado por omgithub.

- Selección **caso a caso con tu OK** (nada se mueve/copia sin decisión explícita).
- **No todo va a omgithub:** parte puede quedar en repos **públicos**; definir con cuidado qué se expone.
- **No exponer nada privado** sin decisión explícita. Revisar antes de extraer.
